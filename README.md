# 🛡️ Detection of Malicious Behavior Using Audit Logs

## 📌 Project Overview

This project focuses on identifying malicious activities within Linux-based systems by analyzing audit logs. By leveraging machine learning techniques, the system aims to detect anomalies and potential threats, enhancing system security and integrity.


![project](https://github.com/SalmaFayad/Malicious_Behavior_Detection_Using_Audit_Logs/assets/54403902/6c3ef188-5865-429e-8d12-eb0e8b96b216)


## 🎯 Objectives

- **Log Parsing**: Extract and preprocess Linux audit logs to identify relevant events.
- **Feature Engineering**: Develop features that capture system behaviors indicative of malicious activities.
- **Model Training**: Utilize machine learning algorithms to train models capable of detecting anomalies.
- **Evaluation**: Assess model performance to ensure accurate threat detection.

## 🛠️ Tools & Technologies

- **Programming Language**: Python
- **Libraries**: Pandas, Scikit-learn, Matplotlib
- **Data Source**: Linux Auditd Logs
- **Machine Learning Algorithms**: Decision Trees, Random Forests, SVM
- **Development Environment**: Jupyter Notebook

## 📁 Repository Structure

- `data/`: Contains sample audit log files for analysis.
- `scripts/`: Python scripts for data preprocessing, feature extraction, and model training.
- `models/`: Directory for storing trained machine learning models.
- `notebooks/`: Jupyter Notebooks for exploratory data analysis and visualization.
